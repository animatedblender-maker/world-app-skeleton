# Mobile Packaging (Capacitor)

This folder packages the web build for iOS/Android using Capacitor.

By default, the native shell now loads `https://matterya.com` directly so the iOS app stays on the exact same version as the live website.

## Quick start
1. From this folder: `npm run cap:sync`
3. Open native projects:
   - `npm run cap:ios`
   - `npm run cap:android`

## Notes
- `webDir` points to `apps/web/dist/web`.
- Native folders (`ios`, `android`) are generated by Capacitor.
- Local packaged builds are still available with:
  - `npm run cap:sync:local`
  - `npm run cap:ios:local`
  - `npm run cap:android:local`
